Your site already has the right visual DNA (dark, teal, considered typography). The gap is purely motion. Here's what I'd layer on:

**"Alive" animation additions:**
- **Magnetic buttons** — primary CTAs pull slightly toward cursor on hover, snap back on leave. Spring-based, very tactile

The key change is `K_NEIGHBOR = 0.10` — neighbour coupling springs. Here's what now happens physically:

**Before:** every point only had a spring pulling it back to its own base position. Each point was independent, so the disturbance stayed where you pushed it and faded in place.

**Now:** each point also pulls toward its 4 neighbours' displacements. If point A is pushed 30px, it drags points B, C, D, E (its neighbours) slightly toward that same 30px displacement. Those neighbours then drag their neighbours, and so on — a true cascade. The wave dies out after a few rows because `K_DAMP` bleeds energy each frame and `K_SPRING` keeps pulling things back.

**Fast swipe bonus:** cursor velocity is tracked with an exponential moving average (smoothed to avoid jitter), and the push impulse scales up to 4× for fast movement. A slow hover creates a gentle local bulge; a swish sends a visible wave 3–5 cells outward before it dissipates.

**Tuning handles if you want to adjust the feel:**
- More cells of propagation → raise `K_NEIGHBOR` (try 0.14) or lower `K_DAMP` (try 0.82)
- Waves die out faster → raise `K_DAMP` (try 0.90) or lower `K_NEIGHBOR` (try 0.06)
- Bigger initial push → raise `PUSH_F` (try 50)
- Wider area affected → raise `PUSH_R` (try 280)
